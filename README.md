A fast, dependency-free JavaScript Markdown renderer that returns byte-for-byte identical HTML to marked 18.1.3 (default options: GFM on) — and renders it faster. `parse.js` is an original single-pass CommonMark 0.31.2 + GFM 0.29 parser written from the specifications; `main.ts` is the driver the harness runs.

## Run it

```sh
node main.ts
```
